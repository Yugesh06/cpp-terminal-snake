# C++ Terminal Snake

## Overview
A terminal-based implementation of the classic Snake game, written entirely in native C++. 

This project was built to practice low-level system interactions, specifically focusing on real-time game loop architecture, memory management, and console rendering without the use of external game engines.

## Key Features
* **Real-Time Game Loop:** Continuous state updating and rendering logic.
* **Coordinate Tracking:** Dynamic spatial tracking for accurate collision detection (walls and self).
* **Console I/O:** Custom terminal rendering and asynchronous user input handling.

## Tech Stack
* Language: C++
* Core Concepts: Memory Management, Event Handling, Real-time Loops
